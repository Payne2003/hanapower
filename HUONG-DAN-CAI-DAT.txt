HANA MEDIA – QUẢN LÝ SẢN XUẤT VIDEO
Hướng dẫn chạy thử trên một máy Windows
==========================================

CÁCH NHANH NHẤT: chạy file HanaMedia-Setup-x.y.z.exe
  - Bộ cài tự cài Node.js, WSL, Docker Desktop (nếu máy chưa có), máy chủ dữ liệu,
    dữ liệu mẫu và tạo biểu tượng "HANA MEDIA" trên màn hình.
  - Chọn "Yes" khi Windows hỏi quyền quản trị. Cần Internet.
  - Lần đầu mất 20–40 phút. Windows có thể yêu cầu khởi động lại MỘT lần;
    sau khi đăng nhập lại, cửa sổ cài đặt tự chạy tiếp.
  - Khi thấy "CÀI ĐẶT XONG": từ nay nhấp đúp biểu tượng HANA MEDIA để mở.
  - Lần đầu mở Docker Desktop có thể hỏi đăng nhập tài khoản Docker: chọn "Skip"/bỏ qua.

CÁCH KHÁC (từ file zip)
  Giải nén, nhấp đúp 1-CAI-DAT.bat — làm đúng các bước như bộ cài.
  Mỗi lần dùng: nhấp đúp biểu tượng HANA MEDIA hoặc 2-MO-UNG-DUNG.bat.
  Ứng dụng mở tại http://localhost:3000. Giữ cửa sổ đen mở trong lúc dùng.

CẬP NHẬT PHIÊN BẢN MỚI (dữ liệu đã nhập được giữ nguyên)
  - Bộ cài: chạy file HanaMedia-Setup bản mới, giữ thư mục cài đặt như cũ.
  - File zip: giải nén file zip mới ĐÈ vào thư mục cũ (chọn "Thay thế tất cả"),
    rồi mở ứng dụng.
  - Nếu tải bằng Git: nhấp đúp 3-CAP-NHAT.bat, rồi 2-MO-UNG-DUNG.bat.
  Khi mở, ứng dụng tự nhận biết bản mới: cài thư viện mới (nếu có), cập nhật cấu trúc
  dữ liệu (không xóa dữ liệu), đóng gói lại. Lần mở đầu tiên sau cập nhật mất thêm 1–2 phút.

LƯU Ý
  - Bản này chạy trên MỘT máy để thử. Để cả đội dùng chung (văn phòng + ở xa)
    cần đưa lên máy chủ hoặc cloud – xem docs/deploy-onprem.md và docs/deploy-cloud.md.
  - Gỡ cài đặt: Settings → Apps → HANA MEDIA → Uninstall.
  - Gặp lỗi: chụp màn hình cửa sổ đen gửi lại để được hỗ trợ.
